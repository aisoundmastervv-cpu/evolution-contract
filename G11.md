# G11 — Semantic Contract Gate

**Status:** REGISTERED — specification pending
**Type:** Semantic validation gate
**Predecessor:** G10 — implementation/technical validation
**Branch:** `validation/real-two-fix`

## Purpose

G11 raises the level of evidence beyond G10. G10 establishes that the implementation passes the repository's technical validation suite. G11 must establish that the implementation's observable behavior conforms to an independently stated semantic contract.

G11 must not merely repeat `cargo fmt`, `cargo check`, `cargo test`, or `cargo clippy`, and a passing implementation test suite is not by itself sufficient evidence of semantic correctness.

## Required specification

Before G11 is executed, the following items must be registered explicitly:

1. **Claim** — the exact semantic proposition being asserted.
2. **Oracle** — the independent source that determines the expected result.
3. **Test cases** — positive cases whose required behavior is specified by the contract.
4. **Negative cases** — cases that the contract requires the implementation to reject or handle as failure.
5. **Evidence** — the machine-readable artifacts and outputs that constitute proof of the Gate result.
6. **Failure rule** — the precise condition under which G11 is considered failed and what happens to the Gate state afterward.

## Independence requirement

The G11 oracle must not be derived solely from the implementation under test or from tests whose expected behavior was generated from that implementation. The Gate must compare implementation behavior against a separately stated semantic requirement.

## Non-goals

G11 does not claim that the entire project, scientific model, or higher-level architecture is correct. It establishes only the semantic property or properties explicitly named in its final Claim.

## State transition

```text
G10 PASS
  -> G11 specification registered
  -> Claim / Oracle / Cases / Evidence / Failure rule frozen
  -> G11 execution
  -> PASS or FAIL with recorded evidence
```

Until the six required items are explicitly specified and frozen, **G11 is REGISTERED but not executable and not passed**.
