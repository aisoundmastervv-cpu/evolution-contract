# G11.1 — Minimal Semantic Baseline

Status: **DRAFT — NOT FROZEN**

## Purpose

Define the smallest G11 semantic claim that is directly supported by the design-level contract, without importing additional state-transition semantics from the current implementation.

G10 established technical/implementation validation of the isolated branch. G11 must establish a stronger proposition: that observable behavior conforms to independently stated semantic requirements.

## Source-of-truth boundary

The baseline is derived only from the design-level contract documented in `README.md` / Evolution Application Contract v1.0. The current Rust implementation, current tests, error variants, helper structure, and control flow are evidence under test, not sources of semantic law.

## Minimal Claim C1

> **For every evolution request admitted by the design-level contract, the implementation preserves the contract's explicitly stated safety and atomicity properties; for requests made stale by intervening evolution, the implementation applies the contract's temporal-tolerance rule.**

The Claim is intentionally limited to properties that the design-level source explicitly states:

- **Capability safety:** authorization/capability requirements are respected.
- **Structural atomicity:** structurally invalid evolution plans do not partially mutate evolution state.
- **Build-then-commit atomicity:** a failed build does not partially commit the resulting evolution.
- **Temporal tolerance:** a request that has become stale is handled according to the contract's tolerance rule rather than invalidating unrelated valid requests.

The Claim does **not** assert any additional exact state-transition semantics that are not explicitly specified by the design-level source.

## Independent Oracle O1

The oracle is a contract-level predicate over observable outcomes:

1. Determine, from the design-level rules alone, whether the request is authorized and structurally admissible.
2. For a structurally invalid request, require the contract's stated atomicity property: no partial evolution-state mutation.
3. For an admissible request whose build fails, require the stated build-then-commit property: no partial committed evolution.
4. For a request that became stale after planning, require the stated temporal-tolerance behavior: the stale request does not invalidate unrelated valid requests.
5. For authorized, structurally valid, successfully built requests, require only that the observable outcome does not violate the explicitly stated contract properties above. Exact genealogy, generation, queue, fossil, and audit transitions remain outside this Gate unless separately specified by the design-level contract.

The oracle must be evaluable without executing or inspecting production implementation logic. It must not call production functions, reuse implementation predicates, inspect internal control flow, or derive expected results from the implementation's own output.

## Independence test

Before G11.1 is frozen, the following must be demonstrated:

- C1 can be stated without naming implementation symbols.
- Every included property has an identifiable design-level source.
- O1 can be evaluated without executing production implementation code.
- Expected outcomes can be determined before observing the implementation result.
- No G11 test is used as a source for defining C1 or O1.
- No implementation detail is promoted to semantic law merely because the current tests assert it.

## Explicit non-claims

This Gate does **not** currently establish:

- a complete abstract state-transition relation;
- exact generation semantics;
- exact genealogy semantics;
- exact runnable-queue semantics;
- exact fossil/death metadata semantics;
- exact audit-state semantics.

Those properties require additional independent normative specification before they can become G11 claims.

## Freeze condition

G11.1 may be marked **FROZEN** only after C1 and O1 have been reviewed against the design-level source and their independence from the current implementation has been demonstrated.

Until then:

> **No G11 tests, no G11 production changes, and no G11 PASS decision.**
